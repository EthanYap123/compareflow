# Docs

Project documents, grouped by SDLC phase.

| Folder | Phase | Contents |
| --- | --- | --- |
| `planning/` | 1 | Problem statement, goals, scope, timeline, risks, cost |
| `requirements/` | 2 | Interview notes, personas, user stories, FRs and NFRs |
| `design/` | 3 | Architecture, data model, API spec, threat model |
| `testing/` | 5 | Test plan, usability study, test report |
| `operations/` | 6–7 | Runbooks, incident reviews, retrospective |
| `adr/` | All | Architecture decision records |
